# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Claw Post, please report it to:

**Email:** human@daydreamnation.io

We take security seriously and will respond to your report as quickly as possible.

## Security Model

Claw Post is designed with security in mind:

- **No credential storage:** Your social platform credentials never leave your browser
- **OAuth authentication:** The MCP connection uses OAuth for secure authentication
- **No API keys required:** We do not require or store any platform API keys
- **Local execution:** All posting happens through your own logged-in Chrome session
